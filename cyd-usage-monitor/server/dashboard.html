Device provisioning

Flash a new CYD

Build locally so private Wi-Fi and device credentials never leave your trusted workstation.

Open complete guide

1 · Prepare secrets

Copy include/secrets.h.example to the ignored include/secrets.h. Add the Wi-Fi, private-LAN monitor URL, and monitor Bearer token.

2 · Connect the board

Use the CYD USB-to-serial/data port and a data-capable cable. Find the port before flashing.

pio device list

3 · Build and upload

Replace COM5 with the detected port. PlatformIO's Build and Upload buttons perform the same actions.

pio run -e esp32-2432S028R
pio run -e esp32-2432S028R --target upload --upload-port COM5

4 · Verify locally

Open the serial monitor at 115200 baud. A working device reaches the LAN-only API and displays the selected account.

pio device monitor --baud 115200 --port COM5

Wokwi · Build and restart

Wokwi uses the same LAN-only build. Build and restart Wokwi, focus its Serial Monitor, then use U, H, N, or ?.

pio run -e esp32-2432S028R

Never commit include/secrets.h or share a compiled firmware binary. Keep the device port private: no router forwarding and no Cloudflare device route.
